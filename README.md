# Investment Ontology

Personal investment knowledge base, ontology, and Neo4j graph tools.

## Contents

- [`ontology/obsidian-vault`](ontology/obsidian-vault): Obsidian notes, investment reviews, ontology JSON, and a relationship canvas.
- [`ontology/neo4j`](ontology/neo4j): Neo4j setup and usage documentation.
- [`ontology/scripts`](ontology/scripts): Setup, synchronization, and verification scripts.
- [`utils.py`](utils.py): Existing utility code.

## Browse the knowledge base

Open `ontology/obsidian-vault` as a vault in Obsidian. Start with `00. 시작하기.md`.

To use the graph tools, change into `ontology` first and follow [the Neo4j guide](ontology/neo4j/README.md).

Local passwords, API credentials, database files, caches, and machine-specific settings are excluded.
