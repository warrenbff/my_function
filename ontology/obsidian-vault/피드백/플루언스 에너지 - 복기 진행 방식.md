# 플루언스 에너지 — 복기 진행 방식

> 분류 정정(2026-09-28): 아래는 분석자의 사후 평가·비교 자료다. 기존 인터뷰 요약과 원 발화를 대조하지 못한 부분은 개인 사고의 확정 근거로 사용하지 않는다. 심리·오류·실패 원인은 가설이며, 사용자 정정과 현재 [[99. 온톨로지 운영 규칙]]을 우선한다.

## 평가 기준의 정정

사용자는 마진이 약 5%로 하락할 것을 누가 예측할 수 있었느냐고 반문했다. 이는 당시 마진을 정확히 맞혀야 했다는 사후 평가 기준에 대한 이의다. 수치 자체는 이 문서에서 검증하지 않았다.

이전 대화에서 ‘가정이 틀렸으므로 Base를 낮췄어야 한다’는 사후 평가를 기록했지만, 이를 원래 매수의 오류나 즉각적인 가치 하향 의무로 확대하지 않는다. 관측된 부진과 장기 가정의 훼손은 구분한다. 결과를 알게 된 지금의 지식을 과거 판단에 소급하지 않는다.

## 진행 순서

1. **당시 판단 복원:** 어떤 마진 회복 경로를 기대했고 무엇을 근거로 삼았는가? 당시 실제로 읽은 자료와 지금 찾아본 자료를 구분한다.
2. **불확실성과 노출 복원:** 기대가 빗나갈 수 있음을 어떻게 생각했으며, 실제 비중과 추가매수 규모는 어느 정도였는가? 사전에 정하지 않은 확률·손실 한도는 만들지 않는다. 누적 매수대금으로 당시 비중을 대신하지 않는다.
3. **첫 부진 인지 시점 복원:** 어떤 발표를 언제 접했고, 당시 일시적 차질과 구조적 변화 중 무엇으로 해석했는가? 기억이 없으면 미기록으로 둔다.
4. **생각과 행동의 연결:** 모델 가정·가치 판단·확신이 바뀌었는가? 유지했다면 근거는 무엇인가? 매수·보유·축소 중 어떤 행동을 했는가?
5. **개선 한 가지:** 확인 가능한 과정상 문제가 있을 때만 다음에 시험할 행동을 정한다. 합리적인 판단의 불리한 결과, 근거 부족, 실행 오류, 판정 불가를 구분한다. 사례 하나로 개인 규칙을 확정하지 않는다.

## 한 사건에 사용할 질문

| 순서 | 질문 | 기록 기준 |
| --- | --- | --- |
| 예상 | 당시 무엇을 기대했나? | 회상과 당시 기록 구분 |
| 근거 | 왜 그렇게 기대했나? | 출처·실제 인지 시점 |
| 변화 | 이후 무엇을 알게 됐나? | 발표 시점과 본인이 안 시점 구분 |
| 해석 | 그때 어떻게 받아들였나? | 당시 해석과 오늘의 평가 구분 |
| 행동 | 그래서 무엇을 했나? | 거래 사실과 이유 분리 |
| 개선 | 다음에는 무엇을 확인할까? | 근거가 없으면 판정 보류 |

## 다음 출발점

최초 진입의 모든 내용을 반복하지 않고 **마진 부진을 처음 알게 된 순간**부터 진행한다. 해당 실적·발표 시점이 기억나지 않으면 ‘처음 기억나는 부진 관련 정보’부터 시작한다. 일시적이라고 봤는지, 장기 가정이 달라졌다고 봤는지, 아직 판단할 수 없었다고 봤는지를 열린 질문으로 묻는다.
