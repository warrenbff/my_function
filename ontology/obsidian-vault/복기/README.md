# 복기 — 사용자 생각의 기록

이 영역은 직접 사용자 진술과 사용자가 작성한 당시 자료로만 과거 생각을 복원한다. 현재 회상은 회상으로 표시한다. 사실과 다르더라도 당시 사용자가 실제로 믿었던 내용은 고치지 않고, 사실 확인은 피드백으로 연결한다.

- 원문: [[복기/진술/2026-09-28 직접 진술]].
- 사례: [[복기/00. 복기 진행판]].
- 구조: [[복기/00. 디지털 트윈 스키마]].
- 외부 사실·AI 해석·새 지식·오류 진단·새 규칙은 [[피드백/00. 피드백 지도]]와 [[투자철학/00. 나만의 투자철학 만들기]]에 쓴다.
- `거래 내역/`은 기존 경로에 남긴 별도 객관 자료다. 거래만으로 이유·감정을 추론하지 않는다.
- `개인 투자 규칙/`의 실제 문서는 투자철학으로 이동했다.

원 사용자 발화와 대조하지 못한 기존 요약은 보존본에 두고 ‘대조 대기’로 연결한다. 질문·미상은 허용하지만 AI가 만든 답을 개인 기억으로 채우지 않는다.
