# 투자 의사결정 디지털 트윈

디지털 트윈은 이상적인 투자자가 어떻게 판단했어야 하는지가 아니라, 사용자가 실제로 어떤 정보를 받아 어떤 판단을 했다고 진술했는지를 보존한다. 확인되지 않은 연결은 비워 둔다.

| 객체 | 필수 정보 | 관계 |
| --- | --- | --- |
| 사용자 진술 | statement_id, 원문, 출처 위치, 작성일, 당시 기록/현재 회상/현재 의견 | 판단을 진술한다 |
| 당시 정보 상태 | 사용자가 읽었다는 근거, 읽은 시점(미상 허용), 자료 | 의사결정에 사용됐다고 진술한다 |
| 의사결정 | decision_id, 결정일(미상 허용), 행동, 이유의 진술 ID | 분석 버전을 사용한다; 거래로 실행된다 |
| 거래 사실 | 데이터 출처, 거래일, 종목, 수량·금액 | 행동 실행을 확인한다. 동기는 증명하지 않는다 |
| 투자 사례 | episode_id, 종목, 연결한 진술·결정·거래 | 동일 투자 흐름을 묶는다 |

외부 자료의 발표일, 내가 읽은 날짜, 결정일, 회상 기록일을 구분한다. 발표됐다는 이유만으로 ‘알고 있었다’ 관계를 만들지 않는다.

## 복기 밖의 객체
결과 관측 → 피드백 → 원인 가설 → 규칙 채택 → 규칙 버전 → 새 분석은 별도 영역이다. 원인 가설은 진술의 근거가 될 수 없다. 사용자 정정은 이전 해석을 철회·수정하지만 당시 원문을 덮어쓰지 않는다.

## 복원 상태
미기록 / 원문 대조 대기 / 직접 회상 확인 / 동시기 기록 확인 / 사용자 정정.

실제 성과 검증·규칙 효과 검증은 별도 상태다. 직접 회상 확인이 당시 기억의 객관적 정확성을 보장하지 않는다.
