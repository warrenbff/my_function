# 미탐지·반대 사례 검증 지도

```mermaid
flowchart LR
  B[현재 병목] --> A[과거 유사 사례]
  A --> C[사례 비교]
  C -->|보강| B
  C -->|반박| R[재평가]
  FN[미탐지 사례] --> F[탐지 실패 분석]
  FP[반대 사례] --> F
  F -->|수정안| Q[정량 계산·게이트]
  Q -->|재생| FN
  Q -->|오탐 점검| FP
```

## 판정의 균형

```text
미탐지 사례를 줄이는 방향 = 민감도 개선
반대 사례를 통과시키지 않는 방향 = 특이도 보존
```

둘 중 하나만 최적화하면 로직이 무너진다. HBM·DRAM처럼 하위 공정이 상위 분류에 묻힐 수 있는 후보는 미탐지 분석으로, 단기 수급·테마 급등처럼 병목으로 오인하기 쉬운 후보는 반대 사례로 등록한다.
