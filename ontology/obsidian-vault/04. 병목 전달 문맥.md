# 병목 전달 문맥

`bottleneck_context`는 탑다운 병목 판정과 바텀업 기업 선별을 잇는 경계 객체다. 동일 유니버스·그룹·근거를 사용했다는 것을 검증한다.

## 필수 필드

| 필드 | 의미 |
| --- | --- |
| `universe_path` | 분석에 쓴 시장 유니버스 파일 |
| `group_code` | 판정된 TRBC 산업 그룹 |
| `rank`, `score` | 병목 순위와 정량 점수 |
| `is_bottleneck_group` | 병목 그룹 여부 |
| `bottleneck_basis` | 병목 실체·지속기간·통제주체·출처 |
| `candidate_pool_passed` | 후보 선별 단계로 넘길 수 있는지 |

`candidate_pool_passed: true`일 때만 텐베거 후보 풀을 만든다. 그렇지 않으면 `reference_only`로 남긴다.

구현 근거: `scripts/bottleneck.py`, `scripts/tenbagger_pick.py`
