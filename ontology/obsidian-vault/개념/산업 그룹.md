# 산업 그룹

TRBC 코드로 식별하는 병목 점수의 기본 분석 단위다. 같은 가치사슬·공급 제약을 공유하는 여러 [[기업]]을 묶는다.

## 핵심 속성

- `group_code`, `group_name`, `market`, `as_of`
- 5팩터 원값·z-score·총점·순위
- 데이터 커버리지

## 관계

- `속한다` → [[섹터]]
- `구성한다` → [[기업]]
- `병목으로 판정될 수 있다` → [[병목]]
- `전달된다` → [[04. 병목 전달 문맥]]
