# 판정 이벤트

특정 기준일의 데이터와 근거를 사용해 내린 판단의 한 번의 기록이다. 현재 결론만 덮어쓰지 않고, 시점별 판단을 보존한다.

## 필수 속성

```yaml
event_id:
event_type: bottleneck | candidate | valuation | reevaluation
decided_at:
decided_by: human | script | hybrid
dataset_id:
subject:
status:
reason_summary:
next_review_at:
```

## 관계

- `사용한다` → [[데이터셋]], [[병목 근거]], [[가치평가]]
- `판정한다` → [[병목]], [[기업]], [[안전마진]]
- `종료된다` → [[의사결정 상태]]
- `업데이트된다` → [[재평가 트리거]]
