# 의사결정 상태

분석의 현재 종료 상태다. 상태는 결론을 간단히 표시하고, 실제 이유와 다음 행동은 [[판정 이벤트]]가 보유한다.

## 허용 상태

`관찰` · `정량 통과` · `병목 확정` · `후보` · `매수 후보` · `보류` · `재평가` · `reference_only` · `중단` · `탈락`

## 상태 전이

```text
관찰 → 정량 통과 → 병목 확정 → 후보 → 매수 후보
  └→ 탈락       └→ 보류       └→ 재평가
```

데이터 품질 실패나 권한 문제는 `중단`으로 기록한다. `reference_only`는 계산은 존재하지만 최종 후보 판정에 사용할 수 없다는 뜻이다.
