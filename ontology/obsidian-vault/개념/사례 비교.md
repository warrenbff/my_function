# 사례 비교

현재 병목과 과거 사례를 같은 표로 맞춰, 무엇이 반복되고 무엇이 달라졌는지 기록하는 객체다.

## 비교 속성

| 차원 | 현재 병목 | 과거 사례 | 판정 |
| --- | --- | --- | --- |
| 수요 원인 |  |  | 동일 / 부분 동일 / 다름 |
| 공급 제약 위치 |  |  | 동일 / 부분 동일 / 다름 |
| 증설·대체 장벽 |  |  | 높음 / 중간 / 낮음 |
| 가격·마진 반응 |  |  | 동일 / 부분 동일 / 다름 |
| 초과이익 귀속 |  |  | 동일 / 부분 동일 / 다름 |
| 해소까지 기간 |  |  | 현재 가설과 비교 |
| 시장·정책 환경 |  |  | 차이 기록 |

## 전이 판정

`high`: 핵심 메커니즘 4개 이상이 동일하고 차이가 결과를 바꾸지 않음  
`medium`: 메커니즘은 같지만 규모·정책·기술 차이가 큼  
`low`: 표면 테마만 같거나 핵심 공급 제약이 다름

## 관계

- `비교한다` → [[병목]], [[과거 유사 사례]]
- `지지하거나 반박한다` → [[주장]]
- `만든다` → [[판정 이벤트]]
