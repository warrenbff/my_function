# 기업

티커로 식별되는 투자 분석 대상이다. [[병목]]에 속했다는 사실만으로 후보가 되지 않으며, 어떤 경로로 이익을 받는지와 [[가치평가]]를 별도로 검증한다.

## 관계

- `속한다` → [[산업 그룹]]
- `수혜를 받을 수 있다` → [[병목]]
- `검증된다` → [[텐베거 가설]]
- `평가된다` → [[가치평가]]
