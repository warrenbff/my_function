# 거래 이벤트

증권사 거래내역서에 기록된 하나의 매수 또는 매도 행이다. 거래 이벤트는 관측된 사실이며, 투자자의 의도나 판단의 질을 의미하지 않는다.

## 필드

| 필드 | 의미 |
| --- | --- |
| event_id | 원본 파일·페이지·행으로 재현 가능한 식별자 |
| date | 거래일 |
| action | `매수` 또는 `매도` |
| instrument_id | 종목코드 또는 ISIN |
| quantity | 거래 수량 |
| notional_krw | 거래대금(원화 환산 표시값) |
| source | 원본 PDF 파일명과 페이지 |

## 관계

| 주어 | 관계 | 목적어 |
| --- | --- | --- |
| 거래 이벤트 | `대상으로_한다` | 기업/ETF |
| 거래 이벤트 | `구성한다` | 투자 사례 |
| 거래 이벤트 | `검증된다` | 거래 내역 데이터셋 |
| 투자 사례 | `해석된다` | 투자 가설 |
| 거래 이벤트 | `발생시킨다` | 포지션 변화 |
