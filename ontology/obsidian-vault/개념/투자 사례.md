# 투자 사례

동일한 종목에 대한 매수·보유·추가매수·축소·매도 흐름을 하나의 복기 단위로 묶은 에피소드다. 거래 이벤트의 단순 합계가 아니라, 하나의 투자 가설이 시작되고 종료되거나 아직 진행 중인 기간을 뜻한다.

## 필드

- `episode_id`
- `instrument_id`
- `start_date`, `end_date`
- `entry_events`, `exit_events`
- `net_quantity_change`
- `realized_result` (별도 평가 자료가 있을 때만)
- `thesis_status`: `미기록 / 복원 중 / 검증 완료`
- `retrospective_status`: `미복기 / 복기 중 / 규칙화 완료`

## 복기 질문

- 처음 산 날의 가설은 무엇이었나?
- 추가매수는 가격 하락, 가설 강화, 자금 유입 중 무엇 때문이었나?
- 매도는 목표 달성, 가설 훼손, 자금 재배치, 감정적 반응 중 무엇이었나?
- 결과와 무관하게 과정은 계획대로였나?

## 관계

`거래 이벤트 → 구성한다 → 투자 사례 → 근거를_가진다 → 투자 가설 → 평가된다 → 복기 결과`
