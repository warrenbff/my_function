# 출처

관측값의 원문을 다시 찾을 수 있게 하는 provenance 객체다. URL만 남기지 않고 문서 제목, 발행일, 확인일, 위치(locator), 출처 등급을 남긴다.

## 필수 속성

```yaml
source_grade: A # A=1차 원문, B=전문 데이터, C=탐색 단서
source_title:
source_url:
locator: # 페이지·표·공시번호·섹션
published_at:
observed_at:
retrieved_at:
```

## 관계

- `지지하거나 반박한다` → [[주장]]
- `묶인다` → [[병목 근거]]
