# 스크리닝과 실행 해석 경계

2026-09-25 사용자는 손절 유예가 있는 규칙을 엄격한 기계적 손절로 설명하면 혼동이 생긴다고 지적하고, 향후 온톨로지·스크리닝에서 이를 구분하도록 요청했다. 이는 해석과 기록 방식의 요구이며 특정 손절선이나 매매 전략의 채택이 아니다.

## 가격 손절의 정확한 분류

『돈의 방향』 PDF 149~152, 155쪽에 근거한다. 기본 설명은 **매수가 대비 -7~8% 가격 손절에 재량적 유예 예외가 있는 규칙**이다. 예외 없는 기계적 손절로 요약하지 않는다.

| 항목 | 원문 또는 해석 | 실행 상태 |
| --- | --- | --- |
| 숫자의 성격 | 149쪽: 저자의 개인적 기준 | 보편 최적값으로 취급하지 않음 |
| 기본 조치 | 151쪽: 비중 축소 / 155쪽: 즉각 청산 | 축소율·전량 여부 미확정 |
| 예외 | 152쪽: 실적 발표 전날·대형 이벤트 직전 잠시 유예 가능, 이벤트 후 원칙 복귀 | 유예 기간·이벤트 범위·복귀 시 처리 미확정 |
| 가격 신호의 의미 | 초기 진입 판단의 오류 가능성에 대응 | 펀더멘털 훼손의 증거로 자동 변환하지 않음 |
| 적용 범위 | 국내 COMP·F-스코어 운용 문맥 | 해외 4팩터에 자동 이식하지 않음 |

예외 조건까지 사전에 객관적으로 정의하면 기계적 운용이 가능할 수 있다. 그러나 현재 책의 설명만으로 그 실행 명세가 완성되었다고 판정하지 않는다. 펀더멘털 유지가 손절 유예를 자동 허용한다는 규칙도 만들지 않는다.

## 스크리닝과 보유 관리의 분리

- 신규 후보의 팩터 점수와 기존 보유 종목의 손절 검토를 별도 결과로 낸다.
- 매수가 대비 하락률을 시장 고점 대비 하락률로 대체하지 않는다. 보유·매수가가 없으면 해당 손절 판정은 적용 대상 없음이다.
- 가격 경계에 닿았다는 사실만으로 기업 퀄리티를 낮추거나 신규 후보를 자동 탈락시키지 않는다.
- 현재 명세로는 가격 경고와 검토 사유까지만 표시한다. 자동 축소·청산 또는 유예 승인으로 승격하지 않는다.
- 미정 값은 미정으로 남긴다. -7% 또는 -8%, 장중 또는 종가, 축소율, 유예 기한을 임의로 선택하지 않는다.
- 원칙·예외·상충 설명·미확정 조건을 함께 검색하고 출력한다. 한 문장만 검색해 단독 실행 규칙으로 쓰지 않는다.

## 점수 산출의 경계

해외 4팩터는 지표와 등급 구간이 있지만 전체 가중치·점수 변환·비교군이 완전하지 않다. 이를 임의 보완한 점수를 책의 정식 점수라고 부르지 않는다. 국내 COMP의 기둥 가중치를 해외 모형에 복사하지 않는다. 산식 미완전 또는 필수 데이터 부재는 0점·탈락이 아니라 산출 불가와 누락 사유로 표시한다.

## 향후 실행 규칙으로 채택할 때 필요한 명세

2026-10-08 사례 보완: [[성상현 부부장/사례/하이닉스 전체 운용 원칙과 유예 재검토]]. 200~201쪽의 외부 충격·근거 유지 보유 원칙과 152쪽의 일시 이벤트 유예는 별개다. 151쪽 비중 축소·155쪽 청산과의 범위·우선순위가 정해지지 않았다면 가격 접촉일을 최종 매도일로 출력하지 않는다. 책 전체를 반영해 달라는 요청이 특정 해석이나 모든 원칙의 사용자 채택을 의미하지도 않는다.

전략·시장, 기준 매수가와 비용·환율 처리, 정확한 하락 임계값, 관찰 가격과 시점, 매도 비중, 유예 대상·시작·종료 조건, 유예 중 손실 한도, 이벤트 후 갭 하락 처리, 재진입 조건을 정한다. 사용자 채택 이벤트와 버전을 별도로 남긴 뒤 실행 가능 여부를 판단한다.

## 해석 확인 사례

| 입력 상황 | 허용되는 설명 | 피해야 할 결론 |
| --- | --- | --- |
| 매수가 대비 -7%, 재무 악화 미확인 | 책의 가격 경계 검토, 실행 조건 미정 | 기업 훼손 확정·전량 자동 매도 |
| 실적 발표 전날 가격 경계 도달 | 원문 유예 가능성 및 승인·기한 미정 표시 | 무조건 손절 또는 무조건 유예 |
| 신규 후보이고 매수가 없음 | 보유 손절 규칙 적용 대상 없음 | 최근 고점 대비 -7%이므로 탈락 |
| 해외주식 정식 점수 요청 | 미공개 산식과 산출 불가 사유 표시 | 임의 가중치로 책의 점수 생성 |
