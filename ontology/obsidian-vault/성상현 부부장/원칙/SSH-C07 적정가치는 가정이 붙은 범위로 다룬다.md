# 적정가치는 가정이 붙은 범위로 다룬다

## 원문에서 추출한 주장

업종에 맞는 배수법·DCF·자산가치로 교차 검토하고, 목표가 하나보다 성장·마진·할인율 가정에 따른 가치 범위를 본다.

근거: [[성상현 부부장/출처/돈의 방향|돈의 방향]] PDF 130, 132, 135, 136, 138, 139, 141, 142, 143, 145, 146, 147쪽. 직접 인용이 아닌 요약이다.

## 관찰할 증거

Bear·Base·Bull별 성장률, 마진, 재투자, 할인율, 영구성장률, 희석주식 수와 각 입력 근거.

## 적용 한계와 반증 질문

아래는 원문을 온톨로지로 옮기면서 붙인 정리자의 점검 기준이다.

낮은 매출 배수는 수익성을 설명하지 않는다. 고성장을 영구히 연장하거나 자산 장부가를 보장된 하방으로 취급하지 않는다.

## 내 복기와 비교할 지점

플루언스의 Base $45.83은 기존 복기 화면의 기록값이다. 이 수치를 현재 적정가치나 검증된 기준으로 승격하지 않고 가정을 비교한다.
