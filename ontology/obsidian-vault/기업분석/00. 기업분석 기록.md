# 기업분석 — 앞으로 쌓을 시점별 기록

현재 이 영역에는 양식과 운영 절차만 있다. 실제 기업 분석이나 사용자 매매 결정을 새로 만들지는 않았다.

1. [[기업분석/템플릿/시점별 기업 분석]]을 `기업명/날짜 분석-v1`로 복제한다.
2. 적용한 개인 규칙과 버전, 정보 기준일, 공개일·열람일을 적는다.
3. 사용자 판단과 분석자 제안을 별도 칸에 적는다. AI 분석 완료를 사용자 매수 결정으로 처리하지 않는다.
4. 새 정보가 나오면 v2 또는 새 날짜 문서를 만들고 이전 분석에 연결한다.
5. 실제 사용자가 결정하면 [[복기/템플릿/의사결정 이벤트 템플릿]]에 원 발화와 사용한 분석 버전을 연결한다.
6. 예상 기한 또는 실적 발표 후 [[피드백/템플릿/예상과 결과 비교]]에서 과거 예상과 대조한다.

적용 규칙: [[투자철학/개인 투자 규칙/PR-001 수요와 공급의 변화 속도 비교]].
