# 시범 실행: 합성 산업 유니버스

이 폴더는 병목 선정 로직의 흐름을 확인하기 위한 **합성 데이터**다. 실제 시장·기업·공급 제약을 뜻하지 않으며 투자 판단에 사용하지 않는다.

시나리오는 세 산업 그룹을 만든다.

| 그룹 | 의도한 성격 |
| --- | --- |
| `5740` | 높은 수요 성장, 마진 확대, 낮은 성장 대비 가격, 강한 초과수익 |
| `5720` | 중간 수준의 성장과 수익성 |
| `5130` | 낮은 성장과 약한 시장 흐름 |

예상 결과는 `5740`이 1위 병목 후보가 되는 것이다. `demo-basis-5740.json`은 입력 형식을 보여 주기 위한 가상 근거이며 실제 출처가 아니다.
