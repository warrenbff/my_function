# 텐베거 후보 선별

[[산업 그룹]] 안의 [[기업]]을 대상으로, 병목 수혜가 3년 10배 가설로 이어질 수 있는지를 선별한다.

## 선별 논리

- 검증된 `bottleneck_context`와 동일한 산업 그룹인지 확인한다.
- 3년 안에 10배가 가능한 시가총액인지 본다.
- 성장률과 마진 확대가 병목 수혜로 설명되는지 확인한다.
- 현재 데이터와 병목 근거가 완전해야 후보 판정에 가치평가를 쓴다.

## 결과

| 상태 | 의미 |
| --- | --- |
| `screenable` | 병목 문맥이 검증되어 후보 분석 가능 |
| `candidate` | 가치평가까지 통과한 기업 후보 |
| `reference_only` | 병목 또는 데이터 근거가 부족한 참고 분석 |

특정 티커에서 시작해도 그 기업의 산업 그룹이 병목인지 역방향으로 확인한다.
