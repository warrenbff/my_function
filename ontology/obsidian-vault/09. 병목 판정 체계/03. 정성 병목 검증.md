# 정성 병목 검증

정량 순위를 “실제 가치사슬 제약”으로 번역하는 단계다. 대표 기업 여러 곳을 하나의 제약으로 설명할 수 있어야 한다.

## 반드시 답할 질문

| 질문 | 통과의 의미 |
| --- | --- |
| 제한 구간은 정확히 어디인가? | 제품명이 아니라 공정·부품·인프라 단계로 특정한다. |
| 수요가 왜 공급을 넘는가? | 수요처·증설 속도·재고를 인과로 설명한다. |
| 누가 제약을 통제하는가? | 공급자, 특허, 인증, 설비, 자원, 전력망 등을 특정한다. |
| 대체와 증설이 왜 어려운가? | 자본·시간·기술·규제·고객 인증 장벽을 적는다. |
| 왜 3년 이상 지속되는가? | 해소 시점과 그 가정을 명시한다. |
| 기업은 어떻게 수혜를 받는가? | 매출, 마진, 점유율, 배수 중 연결 고리를 쓴다. |

## 근거 등급

| 등급 | 근거 | 용도 |
| --- | --- | --- |
| A | 공시, 실적발표, 정부·규제기관, 1차 계약·발표 | 핵심 주장 |
| B | 신뢰 가능한 산업 데이터·전문 리서치 | 보강 주장 |
| C | 언론·시장 논평 | 탐색 단서 |

핵심 주장에는 A 또는 독립적인 B 근거가 필요하다. 출처마다 URL, 제목, 발행일, 확인일, 주장과의 연결을 기록한다.
