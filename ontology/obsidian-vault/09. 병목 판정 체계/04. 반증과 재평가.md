# 반증과 재평가

병목은 영구적 속성이 아니라 시간에 따라 바뀌는 상태다. 확정 노트에는 반드시 해소 조건을 함께 적는다.

## 탈락 또는 하향 신호

| 신호 | 의미 | 조치 |
| --- | --- | --- |
| 공급 증설이 수요를 앞섬 | 제약이 완화될 수 있음 | 지속기간 가설 재검증 |
| 가격·마진 하락 | 가격결정력이 약화됨 | 점수와 기업 수혜 재계산 |
| 고객 재고 조정·주문 취소 | 수요가 과대평가됐을 수 있음 | `보류` 또는 `재평가` |
| 대체 기술·공급자 등장 | 통제력이 약화됨 | 가치사슬 지도 수정 |
| 규제·무역 환경 변화 | 공급·수요 구조 변경 | 근거 업데이트 |
| 데이터 커버리지 하락 | 순위 신뢰도 상실 | `reference_only` |

## 재평가 카드

```yaml
trigger: 증설 발표
expected_direction: 병목 약화
indicator: 신규 생산능력 / 수요 증가율
threshold: 공급 증가율이 수요 증가율을 2개 분기 연속 초과
review_when: YYYY-MM-DD 또는 다음 실적발표
status: open
```

반증은 실패 기록이 아니라 가설의 품질을 높이는 입력이다.
