# 데이터 품질 게이트

점수보다 먼저 데이터가 분석 가능한지 확인한다. 품질을 통과하지 못한 데이터는 순위를 만들지 않는다.

## 필수 확인표

| 확인 항목 | 통과 기준 | 실패하면 |
| --- | --- | --- |
| 시장 구분 | `USA` 또는 `KOR`가 명확 | 수집 중단 |
| 유니버스 | 종목·그룹·시총 정보 존재 | 수집 재실행 |
| 기간 수익률 | 각 기간 커버리지 98% 이상 | 병목 점수 중단 |
| 산업 그룹 표본 | 그룹당 기업 3개 이상 | 그룹 제외 |
| 팩터 관측률 | 각 핵심 팩터 70% 이상 | 정량 통과 불가 |
| 기준일 | 수집일과 데이터 시점 기록 | `reference_only` |

## 기록할 메타데이터

```yaml
as_of: YYYY-MM-DD
market: USA
universe_file: reports/universe-USA-YYYYMMDD.json
universe_count:

  dispersion:

```
