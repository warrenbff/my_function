# 병목 근거 수집법

병목은 뉴스 제목으로 선정하지 않는다. 아래 세 문장이 서로 다른 1차 자료로 확인될 때만 `병목 확정`을 검토한다.

```text
수요: 최종 고객의 실제 구매·사용이 증가한다.
공급: 병목 구간은 일정 기간 안에 충분히 늘릴 수 없다.
가격: 공급 제약의 이익이 이 산업 그룹의 가격·마진에 귀속된다.
```

## 0. 먼저 가치사슬을 한 줄로 쓴다

`최종 고객 → 최종 제품/서비스 → 중간 공정·부품 → 병목 구간 → 공급 기업`

예시: `AI 서비스 고객 → 클라우드 연산 → 데이터센터 → 송전·변압기 → 전력장비 기업`

이 문장이 없으면 “AI”, “친환경”, “방산” 같은 테마와 병목 구간을 혼동하기 쉽다.

## 1. 최종수요를 확인한다

최종수요는 중간 공급자의 매출이 아니라, 가치사슬 끝 고객의 구매·사용량이다.

| 산업 유형 | 우선 지표 | 주된 1차 출처 |
| --- | --- | --- |
| 기업 IT·데이터센터 | 고객 CAPEX, 예약 용량, 사용량, 임대율 | 하이퍼스케일러 실적발표·10-K·IR |
| 소비재 | 판매량, 출하량, 매장 판매, 재구매 | 브랜드·유통사 실적발표, 정부 판매 통계 |
| 산업재 | 고객 주문, 백로그, 설비투자, 생산계획 | OEM·고객사 공시, 조달 계약 |
| 전력·인프라 | 피크수요, 접속 신청, 전력판매, 발전량 | 계통 운영기관·에너지 통계·허가 자료 |
| 원자재 | 최종 제품 생산량, 실물 소비량, 재고 | 제조사 공시, 무역·재고 통계 |

### 최종수요 통과 기준

- 고객 또는 최종 사용자 데이터가 2개 이상 같은 방향을 가리킨다.
- 전년 대비 변화와 절대 규모를 모두 기록한다.
- 일회성 주문, 보조금 선반영, 재고 축적을 수요 증가와 혼동하지 않는다.

## 2. 공급 제약을 확인한다

| 확인할 것 | 측정 지표 | 확인할 자료 |
| --- | --- | --- |
| 현재 공급 | 생산능력, 가동률, 재고, 납기 | 공급사 실적발표·IR·산업 운영 데이터 |
| 증설 속도 | CAPEX, 착공·가동 예정일, 장비 조달 | 공시, 인허가 문서, 프로젝트 발표 |
| 진입장벽 | 기술·특허·인증·규제·원자재·전력·부지 | 사업보고서 위험요인, 규제기관 자료 |
| 대체 가능성 | 대체 공급자·기술의 성능·비용·인증기간 | 고객·공급사 공시, 기술 자료 |

### 공급 제약 통과 기준

- 수요 증가보다 공급 증가가 느린 이유가 하나 이상 명확하다.
- 증설 완료 예상 시점과 3년 지속 가설을 적는다.
- “설비가 부족하다”가 아니라 어느 공정·품목·지역이 부족한지 특정한다.

## 3. 가격결정력과 이익 귀속을 확인한다

| 확인할 것 | 양(+)의 신호 | 반대 신호 |
| --- | --- | --- |
| 가격 | ASP·계약단가 상승, 할증, 가격 인상 | 할인·가격 하락 |
| 수익성 | 매출총이익률·EBITDA 마진 확대 | 비용 부담으로 마진 하락 |
| 계약력 | 장기계약, 선급금, 최소구매약정 | 고객 취소·단기 경쟁입찰 |
| 귀속 대상 | 특정 공급 기업의 점유율·마진 개선 | 고객·원재료 공급자가 이익을 흡수 |

가격이 올라도 원재료 가격 상승을 단순 전가한 결과라면 가격결정력 증거가 아니다. 가격과 마진이 함께 개선되는지 본다.

## 4. 출처 우선순위

| 등급 | 출처 | 사용할 주장 |
| --- | --- | --- |
| A | 사업·분기보고서, 실적발표, 정부·규제기관, 계통 운영기관, 계약·허가 원문 | 병목 확정의 핵심 주장 |
| B | 산업협회, 신뢰 가능한 전문 데이터, 독립 리서치 | 규모·비교 보강 |
| C | 언론, 블로그, 증권사 요약 | 탐색 단서만 |

미국 상장사는 SEC EDGAR, 한국 상장사는 DART에서 원문 공시를 찾는다. 전력처럼 실물 제약이 있는 산업은 에너지·계통 운영기관 데이터가 기업 발표보다 우선할 수 있다.

## 5. 증거 기록 카드

각 주장마다 아래 블록 하나를 만든다. 리서치 노트의 `근거` 표에도 같은 내용을 요약한다.

```yaml
claim: "미국 특정 지역의 데이터센터 전력 접속 대기기간이 증가한다"
pillar: supply                 # demand | supply | pricing
metric: "접속 대기기간"
value: "24개월"
comparison: "전년 14개월"
as_of: YYYY-MM-DD
source_grade: A
source_title: "문서 제목"
source_url: "https://..."
published_at: YYYY-MM-DD
observed_at: YYYY-MM-DD
supports: "`산업 그룹명 병목 카드` (실제 작성 시 해당 노트 링크로 교체)"
limitation: "특정 지역 데이터이며 전국을 대표하지 않음"
```

## 6. 확정 전 마지막 점검

- [ ] 수요 근거가 최종 고객 또는 최종 사용량에서 시작한다.
- [ ] 공급 제약의 위치와 증설 시점을 특정했다.
- [ ] 가격 또는 마진에서 수혜가 확인된다.
- [ ] 세 근거가 서로 다른 출처에서 같은 결론을 지지한다.
- [ ] 병목 해소 또는 반증 조건을 적었다.
