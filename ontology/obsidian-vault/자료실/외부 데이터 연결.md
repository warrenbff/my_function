# 외부 데이터 연결

토스증권 공식 Open API에서 종목 정보·현재가·보유주식을 조회해 기업 분석의 근거로 사용한다. **외부 사실 → 기업 분석 → 사용자 판단 → 이후 복기** 순서로 연결하며, 시세와 거래 정보만으로 과거 매수·매도 이유를 만들어 넣지 않는다.

## 조회 기능

기존 세컨드브레인 MCP에 `toss_status`와 `toss_fetch`를 추가했다. 새 세션에서 “토스 연결 상태 확인해줘”, “토스에서 하이닉스 000660, 플루언스 FLNC, POET 종목 정보와 현재가를 가져와줘”라고 요청한다. 설정 여부와 실제 인증 성공은 다르다. MCP 조회는 파일이나 투자 원칙을 자동 수정하지 않는다.

| 대상 | 제공 데이터 | 해석 경계 |
| --- | --- | --- |
| stocks | 종목명, 시장, 통화, 상장 상태, 발행주식수 등 | 재무제표가 아님 |
| prices | 현재가, 통화, 원천 시각 | 원천 시각이 없을 수 있음 |
| accounts | 연결 계좌 목록 | 개인정보. 필요할 때만 조회 |
| holdings | 국내·미국 보유종목, 수량, 평균 매수가, 손익 | 현재 보유 상태이며 전체 거래 원장이 아님 |

매출·영업이익·마진은 별도 공시 데이터 연결이 필요하다. 공식 API의 과거 주문 조회와 캔들은 이번 도구에 아직 구현하지 않았다. 주문 실행 기능도 포함하지 않는다.

## 원자료 저장과 검색

프로젝트 루트에서 실행한다.

```powershell
python scripts/toss_data.py status
python scripts/toss_data.py stocks --symbols 000660,FLNC,POET --save
python scripts/toss_data.py prices --symbols 000660,FLNC,POET --save
```

원자료 JSON은 `reports/toss-api/snapshots/`, 출처와 해시를 담은 노트는 `자료실/외부 데이터/`에 추가된다. 이전 수집본을 덮어쓰지 않는다. 노트를 Neo4j 검색에 반영할 때는 `neo4j/sync.ps1`을 실행한다. 자동 주기 수집은 등록하지 않았다.

보유주식은 `holdings --account-seq <계좌 식별자>`로 조회한다. 식별자는 `accounts` 응답의 `accountSeq`이며 계좌번호와 다르다. 개인정보가 포함된 원자료는 로컬에 보관한다.

## 인증과 시점

키는 `integrations/toss.local.json` 또는 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET` 환경변수에서 읽는다. 키 파일과 토큰 캐시는 Git에서 제외한다. 키를 분석·복기 문서에 붙여 넣지 않는다. IP가 바뀌면 토스증권 WTS의 Open API 허용 IP를 갱신한다. 같은 키를 쓰는 다른 프로그램이 새 토큰을 발급하면 기존 토큰이 무효화될 수 있다.

`fetched_at`은 수집 시각이다. 공시일·거래일·사용자가 알게 된 날짜가 아니다. 원자료의 시점과 수정 여부는 별도 검증한다. 외부 자료는 [[기업분석/00. 기업분석 기록]]의 근거로 연결하고, 개인 생각은 사용자 진술로만 기록한다. 새 지식에서 얻은 교훈은 [[피드백/00. 피드백 지도]]를 거쳐 채택 여부를 판단한다.

공식 근거: [개발자 문서](https://developers.tossinvest.com/), [REST 스키마](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json), [인증과 제한](https://openapi.tossinvest.com/openapi-docs/overview.md), [FAQ](https://openapi.tossinvest.com/openapi-docs/faq.md). 확인한 스키마 버전은 1.2.24이며 원본은 `reports/toss-api/`에 보존했다.
