# 투자 의사결정 디지털 트윈 스키마

## 핵심 엔터티

| 엔터티 | 역할 |
| --- | --- |
| 거래 내역 데이터셋 | 증권사 원본의 버전 |
| 거래 이벤트 | 하나의 매수·매도 사실 |
| 포지션 상태 | 특정 시점의 수량·평균단가·비중 |
| 투자 사례 | 하나의 투자 가설이 유지된 에피소드 |
| 정보 상태 | 당시 이용 가능했던 정보의 묶음 |
| 투자 가설 | 당시 믿었던 원인·변화·수익 경로 |
| 의사결정 이벤트 | 매수·추가매수·보유·축소·매도·관망 판단 |
| 결과 관측 | 가격·사업·가설의 실제 변화 |
| 판단 오류 | 가설 오류, 정보 오류, 실행 오류 |
| 개인 투자 규칙 | 반복 패턴에서 승격한 행동 규칙 |

## 관계

```text
거래 데이터셋 → 거래 이벤트 → 포지션 상태
포지션 상태 → 투자 사례
투자 사례 → 정보 상태 → 투자 가설
투자 가설 → 의사결정 이벤트 → 거래 이벤트
투자 가설 → 결과 관측 → 판단 오류/가설 적중
판단 오류·적중 → 개인 투자 규칙
개인 투자 규칙 ↔ 병목·기업·가치평가 탐색
```

## 상태값

- `기록`: 거래 사실만 확인
- `복원 중`: 당시 판단 자료를 수집하는 중
- `복원 완료`: 가설과 결정 근거를 재구성함
- `검증 완료`: 결과와 비교해 적중·실패를 판정함
- `규칙화 완료`: 반복 패턴을 개인 규칙으로 승격함

## 신뢰도

- `원본`: 거래내역서·당시 문서로 확인
- `동시기 기록`: 당시 작성한 메모·메시지
- `회고 기록`: 나중에 기억을 복원한 내용
- `추정`: 근거가 부족한 가설적 복원
