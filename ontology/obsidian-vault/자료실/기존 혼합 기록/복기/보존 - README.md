# 투자 복기

이 폴더는 내 투자 세컨드 브레인의 중심이다. 실제 투자 경험을 복기해 내 사고과정을 이해하는 것이 첫 목표다. 거래 사실과 당시의 믿음, 행동, 결과, 사후 학습을 분리해 저장한다. 외부 기준과 병목 근거는 나중에 연결한다.

거래 사실은 [[복기/거래 내역/거래내역 기초 집계 2024-2026]]에서 확인한다. 이 문서는 집계이며 원본 PDF 자체는 아니다.

## 디지털 트윈의 다섯 층

1. 사실: 거래 이벤트, 가격, 보유 수량, 당시 공개 정보
2. 인식: 당시 알고 있던 정보와 정보의 출처
3. 판단: 투자 가설, 기대 시나리오, 확률, 확신
4. 행동: 매수, 추가매수, 보유, 축소, 매도, 관망
5. 결과와 학습: 실현 결과, 가설 검증, 오류, 수정 규칙

## 폴더 구조

```text
복기/
├─ 거래 내역/       # 거래 사실 집계와 원본·정규화 데이터 연결
├─ 투자 사례/       # 종목별·가설별 에피소드
├─ 의사결정/        # 개별 판단 이벤트
├─ 투자 가설/       # 당시의 믿음과 시나리오
├─ 판단 오류/       # 가설 오류와 실행 오류
├─ 개인 투자 규칙/  # 반복 패턴에서 승격한 규칙
└─ 템플릿/          # 기록 형식
```

## 작성 규칙

- 거래내역서에서 확인한 사실과 기억에 의한 복원을 구분한다.
- 사후 결과를 당시의 확신이나 정보로 소급하지 않는다.
- 알 수 없는 값은 `미기록`, 불확실한 복원은 `추정`으로 표시한다.
- 외부 원칙·병목·가치평가 연결은 후속 확장으로 두며 복기의 필수 항목으로 요구하지 않는다.
- 반복되는 생각과 미해결 질문을 먼저 남긴다. 모든 복기에서 오류나 투자 규칙을 확정할 필요는 없다.
- 하나의 거래 행은 거래 이벤트이고, 하나의 투자 가설이 시작·변경·종료되는 기간은 투자 사례다.

## 검증 방향

```text
복기 → 개인 규칙 → 병목·기업 발굴의 검증 항목
탐색 → 새 판정 이벤트 → 과거 사례와의 유사성·반증 검증
```
