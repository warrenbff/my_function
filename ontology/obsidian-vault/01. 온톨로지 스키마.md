# 온톨로지 스키마

## 영역과 소유권

전체 시작점은 [내 투자 작업실](00.%20시작하기.md)이다. 엔터티를 연결하기 전에 기록의 영역과 판단 주체를 구분한다.

| 영역 | 소유하는 기록 | 다른 영역과의 관계 |
| --- | --- | --- |
| 내 복기 | 사용자 원문에 근거한 당시 가설·판단과 현재 회상 | 거래 사실은 별도 연결; 오류 진단은 피드백으로 분리 |
| 성상현 부부장 자료 | 저서의 투자 시퀀스, 외부 원칙, 출처와 문서 관측 | 비교할 외부 관점을 제공한다 |
| 내 투자철학 | 원칙 비교, 사용자 채택·보류·수정 이력과 규칙 버전 | 적용 채택과 효과 검증을 구분한다 |
| 기존 투자 발굴 도구 | 병목·기업·가치평가의 분석과 판정 | 검증된 개인 규칙을 적용하고 새 판단을 기록한다 |
| 월가아재 Wiki | 별도 저자의 공개 자료와 검토 증거 | 저자와 증거 ID를 유지하며 참조한다 |
| 공통 개념 | 기업, 출처, 주장, 판정 등의 정의 | 각 영역에서 같은 정의를 참조한다 |

폴더 위치는 탐색을 돕고, 온톨로지의 관계는 기록의 의미를 설명한다. 외부 원칙을 연결했다고 사용자가 채택한 것으로 처리하지 않는다. 과거 분석 도구의 판정도 실제 개인 매매의 근거로 소급하지 않는다.

## 상태값

`관찰 → 후보 → 매수 후보 → 보류 / 재평가 / 중단`

`reference_only`는 근거 또는 데이터 품질이 부족해 계산값을 최종 후보 판정에 쓰지 않는 상태다.

## 개인 투자 복기 영역

실제 과거 의사결정은 [[복기/00. 디지털 트윈 스키마|복기 디지털 트윈]]에서 관리한다. 기존 분석 엔터티를 복제하지 않고, 다음 관계로 연결한다.

```text
거래 이벤트 → 투자 사례 → 투자 가설 → 의사결정 이벤트
의사결정 이벤트 → 판정 이벤트
투자 가설 → 주장·병목·가치평가
복기 + 별도 결과 관측 → 피드백의 원인 가설 → 사용자 채택 → 개인 투자 규칙
개인 투자 규칙 ↔ 병목·기업 발굴 프로세스
```

## 외부 투자철학 비교 영역

| 엔터티 | 역할 | 필수 속성 |
| --- | --- | --- |
| [[개념/외부 투자 원칙]] | 저자의 출처 기반 투자 주장 | 저자, source_id, source_pages, 주장 유형, 적용 조건, 검증·채택 상태 |
| [[개념/원칙 비교]] | 외부 원칙과 개인 사례의 비교 | 외부 원칙 ID, 복기 사례, 당시 정보, 공통·충돌·기회비용 |
| [[개념/원칙 채택 이벤트]] | 사용자의 선택과 변경 이력 | 결정자, 결정일, 결정, 문장, 이유, 예외, 이전 이벤트 |

| 주어 | 관계 | 목적어 | 필수 속성 |
| --- | --- | --- | --- |
| 외부 투자 원칙 | `출처가_있다` | 출처 | PDF 페이지, 판본, 확인일 |
| 외부 투자 원칙 | `문서_관측으로_확인된다` | 문서 관측 | 원문 명세인지 실제 시장 관측인지 구분 |
| 외부 투자 원칙 | `비교된다` | 원칙 비교 | 원칙 ID |
| 투자 사례 | `비교에_사용된다` | 원칙 비교 | 의사결정 시점, 당시 가용 정보 |
| 원칙 비교 | `결정의_근거가_된다` | 원칙 채택 이벤트 | 비교 근거, 결정 이유 |
| 원칙 채택 이벤트 | `검증_후_승격한다` | 개인 투자 규칙 | 반복 사례, 반대 사례, 검증 상태 |

`성상현 부부장/`은 외부 원칙, `복기/`는 개인 경험, `투자철학/`은 비교·채택을 보관한다. 출처에서 확인한 저자의 명세는 실제 시장에서 관측한 사실과 구분한다. 원칙의 채택 상태는 `미정 / 채택 / 수정 채택 / 보류 / 기각 / 철회`이며 기존 매수 후보 상태와 별개다.

시작점: [[성상현 부부장/00. 성상현 부부장 투자철학 지도]] · [[투자철학/00. 나만의 투자철학 만들기]].


## 세컨드 브레인 v2 — 개인 경험에서 다음 판단으로

2026-09-28 사용자의 경계 지시를 반영한다. 위의 `복기 결과 → 판단 오류 → 개인 규칙`은 자동 확정 관계가 아니다. 아래 증거·판단 주체를 거쳐야 한다.

| 주어 | 관계 | 목적어 | 필수 속성 |
| --- | --- | --- | --- |
| 사용자 진술 | 당시 판단을 진술한다 | 개인 가설·의사결정 | 원문·출처·기록일·회상 여부 |
| 의사결정 | 사용했다고 진술한다 | 정보·분석 버전 | 진술 ID·실제 인지 시점(미상 허용) |
| 거래 사실 | 실행을 확인한다 | 의사결정의 행동 | 거래 출처; 동기 추론 금지 |
| 결과 관측 | 비교된다 | 당시 예상 | 각 기준일·출처·예상 기간 |
| 피드백 | 원인을 가설화한다 | 예상과 결과의 차이 | 작성자·확신·대안·사용자 정정 |
| 외부 지식 | 보완한다 | 피드백·새 분석 | 출처·취득일; 과거 인식 소급 금지 |
| 사용자 채택 이벤트 | 적용한다 | 개인 규칙 버전 | 채택일·원문·효과 검증 상태 |
| 기업 분석 | 적용한다 | 규칙 버전 | 분석일·정보 기준일·작성자 |
| 기업 분석 | 갱신한다 | 이전 분석 | 변경 이유·새 증거·이전 ID |
| 제품 수요 시나리오 | 비교된다 | 실효 공급 시나리오 | 같은 제품·단위·기간·재고·시나리오 |
| 수급 차이 | 근거가 된다 | 병목 가설 | 부족 시점·해소 경로·반증 |
| 병목 가설 | 이익 귀속을 검증한다 | 기업 | 가격결정력·원가·경쟁・현금흐름 |

공통 최소 필드: `id`, `type`, `author`, `recorded_at`, `as_of/event_date`, `source_ids`, `previous_id`(해당 시). 미래 분석은 `applied_rule_versions`, 사용자 결정은 `statement_ids`를 추가한다.

규칙의 적용 상태와 효과 검증 상태를 분리한다. 자세한 개인 정보 경계는 [[복기/00. 디지털 트윈 스키마]], 수급 단위는 [[프로세스/수요와 실효 공급 비교]]를 따른다.
