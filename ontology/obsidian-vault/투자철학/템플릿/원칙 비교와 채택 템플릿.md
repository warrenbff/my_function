# 원칙 비교와 채택 템플릿

복제한 뒤 `type`을 `principle-comparison`으로 변경하고, 실제 기록 ID와 날짜를 넣는다. 아래 미입력 항목은 실제 사실이나 채택 결정이 아니다.

| 항목 | 기록 |
| --- | --- |
| 비교 ID·작성일 | 미입력 |
| 외부 원칙·출처·PDF 쪽수 | 미입력 |
| 복기 사례·의사결정 시점 | 미입력 |
| 당시 내 가설과 행동 | 미입력 |
| 당시 이용 가능했던 자료 | 미입력 |
| 공통점·충돌·적용 불가 사유 | 미입력 |
| 이 원칙이 바꿨을 행동 | 미입력 |
| 방지했을 손실과 놓쳤을 기회 | 미입력 |
| 반대 사례와 예외 | 미입력 |
| 검증에 필요한 다음 자료 | 미입력 |

## 사용자 결정 이벤트

| 항목 | 기록 |
| --- | --- |
| 이벤트 ID·결정일·결정자 | 미입력 |
| 결정 | 미정 |
| 내가 선택한 규칙 문장 | 미입력 |
| 원문에서 수정한 부분과 이유 | 미입력 |
| 적용 시장·기간·증거 수준 | 미입력 |
| 예외·무효화·재검토 조건 | 미입력 |
| 지지 사례·반대 사례 | 미입력 |
| 이전 결정 이벤트 | 없음 또는 이전 ID |
| 개인 규칙 승격 여부와 근거 | 검증 전 |

결정 변경은 새 이벤트로 덧붙인다. 사후 비교로 추정한 행동을 과거의 실제 행동으로 기록하지 않는다.
