# 개인 투자 규칙

이 폴더의 규칙은 처음부터 원칙으로 가정하지 않는다. 여러 투자 사례의 복기에서 반복성과 설명력이 확인된 뒤 승격한다.

## 규칙 승격 조건

- 서로 다른 사례에서 반복된다.
- 결과가 아니라 의사결정 과정의 공통점으로 설명된다.
- 반대 사례와 예외 조건을 함께 기록할 수 있다.
- 미래의 병목·기업 발굴에서 사전에 검사할 수 있다.

## 규칙 카드

```text
규칙:
근거가 된 사례:
적용 조건:
예외 조건:
검증할 탐색 단계:
무효화 조건:
```



## 2026-09-28 분류 정정

이 문서는 사후 분석·방법 또는 규칙이며 사용자 과거 진술의 원본이 아니다. 사용자 심리·오류에 관한 분석자 문장은 가설로 취급한다. 현재 분류 기준은 [[99. 온톨로지 운영 규칙]]을 따른다.


## 적용 채택과 검증 구분
사용자가 앞으로 적용하겠다고 선택한 규칙은 검증 전에도 등록한다. ‘검증된 규칙’ 표시는 위 반복성·반대 사례 조건을 충족한 뒤 별도로 부여한다.

현재: [[투자철학/개인 투자 규칙/PR-001 수요와 공급의 변화 속도 비교]] — 적용 채택, 효과 미검증.
